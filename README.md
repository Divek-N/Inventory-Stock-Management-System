# Inventory & Stock Management System

A web-based inventory management application built using Python Flask, MySQL, HTML, CSS, JavaScript, and Power BI.

## Features
- Product inventory management
- Stock-in and stock-out tracking
- Low-stock identification
- Inventory dashboard and stock valuation
- Product search and category filtering
- Power BI inventory and stock movement report

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask REST API
- **Database:** MySQL
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Microsoft Power BI

## Project Files
- `app.py` — Flask application
- `templates/index.html` — web interface
- `Inventory.pbix` — Power BI report

## Setup
1. Clone this repository.
2. Install the required Python packages.
3. Configure your MySQL database and environment variables.
4. Run the Flask application.
